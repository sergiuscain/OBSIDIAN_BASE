Тернарный оператор `?` - это сокращённая форма if-else,
которая вычисляет одно из двух выражений в зависимости от условия
и возвращает результат.
### Синтаксис
результат = условие ? выражение1 : выражение2;
### Пример:
```c#
int max = a > b ? a : b;
```
Данная программа выведет: Да, 2+3 равно 5.
```c#
Console.WriteLine(2 + 3 == 5 ? "Да, 2+3 равно 5" : "Нет, 2+3 не равно 5");
```
То есть, если условие верно, выводится выражение1, иначе выражение2
