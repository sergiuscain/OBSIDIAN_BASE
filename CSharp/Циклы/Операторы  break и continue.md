Для управления ходом цикла используются специальные операторы:

`break` — немедленно прерывает выполнение цикла и передаёт управление на следующую инструкцию после цикла. **Пример:** поиск элемента в массиве
```c#
for (int i = 0; i < arr.Length; i++) 
	{ if (arr[i] == target) 
		{ 
			index = i; break; // прекращаем поиск после нахождения 
		} 
	}
```
`continue` — пропускает оставшуюся часть текущей итерации и переходит к следующей. **Пример:** вывод нечётных чисел от 1 до 10.
```c#
for (int i = 1; i <= 10; i++) 
	{ 
		if (i % 2 == 0) 
			{ 
				continue; // пропускаем чётные числа 
			} 
			Console.WriteLine(i); 
	}
```
