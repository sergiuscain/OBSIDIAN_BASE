**Идея:** многократно проходим по массиву и сравниваем соседние элементы. Если они стоят не по порядку - меняем их местами. За каждый проход самый большой элемент всплывает в конец, как пузырёк.
### Реализация
```csharp
static void BubbleSort(int[] array)
{
	for (int i = array.Length - 1; i > 0; i--) // на какое место будем ставим наибольший элемент
	{
		for (int j = 0; j < i; j++) // проходим по не отсортированной последовательности
		{
			if (array[j] > array[j + 1])// если порядок элементов неправильный
			{
				// меняем местами пары
				int temp = array[j];
				array[j] = array[j + 1];
				array[j + 1] = temp;
			}
		}
	}
}
```
### Реализация с оптимизацией
Можно заметить, что если на одном из очередных проходов окажется, что обмены больше не нужны, то это будет означать, что все элементы находятся на своих местах, то есть массив отсортирован. Тогда давайте перед очередным проходом поставим переменную флажок, по которому будем понимать, были ли перестановки элементов. Изменим значение флажка при обмене элементов. Если после цикла флажок останется в том же состоянии, как до прохода, значит массив отсортирован и пора прекращать проходы.
```csharp
static void BubbleSort(int[] array)
{
	for (int i = array.Length - 1; i > 0; i--) // на какое место будем ставим наибольший элемент
	{
		bool flag = false; // false - не было обменов, true - был хотя бы 1 обмен
		for (int j = 0; j < i; j++) // проходим по не отсортированной последовательности
		{
			if (array[j] > array[j + 1])// если порядок элементов неправильный
			{
				// меняем местами пары
				int temp = array[j];
				array[j] = array[j + 1];
				array[j + 1] = temp;
				flag = true; // меняем флажок
			}
		}
		if(flag == false) // если значение флага не поменялось
		{
			return; // массив отсортирован. Выходим с функции
		}
	}
}
```

### Свойства алгоритма сортировки пузырьком

|Свойство|Ответ|Комментарий|
|---|---|---|
|Устойчивость|Да|При равенстве элементов не происходит переупорядочивания элементов|
|Внутренняя/внешняя сортировка|Внутренняя|Нужно несколько раз пробегать по последовательности|
|Естественность поведения|Да|При частичном сортированном массиве алгоритм не будет менять их относительный порядок и сработает быстрее обычного|
