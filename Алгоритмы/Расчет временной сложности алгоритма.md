# Асимптотическая сложность (Big-O)
Правило получения из точной функции сложности:
1. Отбросить все слагаемые, кроме **самого быстрорастущего**.
2. Отбросить **константы**.
Пример: `O(4n + 2) → O(n)`, `O(5n² + 5n + 3) → O(n²)`.
### Основные классы сложностей (по возрастанию)
| Сложность    | Название                | Пример                                    |
| ------------ | ----------------------- | ----------------------------------------- |
| `O(1)`       | константная             | доступ к элементу массива, `a + b`        |
| `O(log n)`   | логарифмическая         | бинарный поиск                            |
| `O(n)`       | линейная                | один цикл по `n`                          |
| `O(n log n)` | линейно-логарифмическая | эффективные сортировки (merge/quick sort) |
| `O(n²)`      | квадратичная            | вложенные циклы по `n`                    |
| `O(n³)`      | кубическая              | тройная вложенность                       |
| `O(2ⁿ)`      | экспоненциальная        | перебор подмножеств                       |
| `O(n!)`      | факториальная           | перебор перестановок                      |
Чем выше класс — тем быстрее растёт число операций при увеличении `n`.

### Как считать на практике
- Последовательные блоки → **складываются** (`O(n) + O(n²) = O(n²)`).
- Вложенные циклы → **перемножаются** (`n × n = O(n²)`).
- Цикл, уменьшающий `n` вдвое → `O(log n)`.
- Константы и младшие слагаемые отбрасываются.

### Зачем это нужно
- Сравнивать алгоритмы одной задачи.
- Выбирать алгоритм под размер входных данных: например, `2n²` лучше `100n` при `n < 50`, но хуже при `n > 50`. Поэтому акцент — на **поведении при больших `n`**.
