Секрет передают контейнеру при запуске флагом `-e`, тогда он живет только на этой машине и в образ не попадает.
Хранить секрет в коде не безопасно (например, пароль от базы данных в файле appsettings.json)

В Json файле настройки вложены друг в друга. Для обращения к вложению используют двойное подчеркивание `__`
Пример: 
`-e ConnectionStrings__Postgres="Host=db;Port=5432;Database=reviews;Username=postgres;Password=prod-secret` - при запуске контейнера с таким флагом, будет использоваться строка подключения из флага -e. Строка из appsetings будет использоваться только, если запускать контейнер без флага (то есть, флаг имеет высший приоритет, чем код а appsettings)
```` 
```json
{
  "ConnectionStrings": {
    "Postgres": "Host=db;Username=postgres;Password=secret"
  }
}
```
