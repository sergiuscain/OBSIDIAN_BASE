`-d` от слова detach, фоновый режим. Контейнер работает в фоне, терминал сразу свободен для следующих команд.
Что будет без этого флага. Контейнер займет твой терминал и начнет писать в него логи. Закроешь терминал, контейнер остановится.

`--name my-postgres` задает имя контейнера. По нему ты будешь к нему обращаться.
Что будет без этого флага. Docker придумает имя сам, и оно будет вроде `nervous_tesla` или `boring_hopper`. Работать будет, но обращаться неудобно.

`-p 5432:5432` это проброс порта. Слева порт на твоем компьютере, справа порт внутри контейнера.
Контейнер изолирован, и его порты по умолчанию снаружи не видны. Этот флаг говорит, что все, что придет на порт 5432 твоего компьютера, надо отправлять на порт 5432 внутрь контейнера.
Запомнить порядок легко. Слева то, что ты набираешь сам, в браузере, в DBeaver, в строке подключения.

`-e POSTGRES_PASSWORD=secret` передает переменную окружения. Так настраивают контейнеры.
Образ PostgreSQL читает эту переменную при первом запуске и устанавливает пароль пользователя. Без нее база просто откажется стартовать.
Флагов `-e` можно передать сколько угодно:
```
docker run -d --name my-postgres -p 5432:5432 \
  -e POSTGRES_USER=devuser \
  -e POSTGRES_DB=myapp \
  -e POSTGRES_PASSWORD=secret \
  postgres:17-alpine
```
